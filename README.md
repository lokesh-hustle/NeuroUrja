# NeuroUrja

Brain-inspired multi-building clean energy dashboard (hackathon Track #7).

## Run

```bash
npm install
npm run dev
```

Open the printed local URL (usually `http://localhost:5173`).

Use the four **Judge Scenario Simulator** buttons in the header to switch campus state instantly. Toggle **Live Simulation Tick** to let charts and kW numbers drift every 2 seconds.
